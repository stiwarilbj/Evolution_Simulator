# Git commits and GitHub

- Use the global Git identity `stiwarilbj` with `stiwarilbj@gmail.com`.
- For each request about this project, add a brief note to `PROJECT_LOG.md`. Record what changed or what was decided, even if the reply needed no code changes. Keep private chat details out of the log.
- After the work and checks are done, commit the note and the changes for that request. Push to the current branch's GitHub upstream. If the branch has no upstream, push it and set the upstream.
- Keep unrelated work out of the commit. Do not amend commits, force-push, or switch branches by default. If the commit or push is blocked, explain why.
